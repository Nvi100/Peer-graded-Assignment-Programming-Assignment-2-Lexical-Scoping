# Getting and Cleaning Data - Course Project

This repository contains the R code and documentation files for the Coursera "Getting and Cleaning Data" course project. 

The purpose of this project is to demonstrate the ability to collect, work with, and clean a data set to prepare tidy data that can be used for later analysis.

## Dataset

The data used in this project represents data collected from the accelerometers from the Samsung Galaxy S smartphone. A full description is available at the site where the data was obtained:

* **Source Overview:** [Human Activity Recognition Using Smartphones](http://archive.ics.uci.edu/ml/datasets/Human+Activity+Recognition+Using+Smartphones)
* **Data Download:** [UCI HAR Dataset.zip](https://d396qusza40orc.cloudfront.net/getdata%2Fprojectfiles%2FUCI%20HAR%20Dataset.zip)

## Files in this Repository

* `run_analysis.R`: The R script that downloads the dataset, processes it, and generates the final tidy dataset.
* `tidy_data.txt`: The final output data generated by running the R script. It contains the averages of the mean and standard deviation measurements for each subject and activity.
* `CodeBook.md`: A code book that describes the variables, the data, and the transformations/clean-up work performed to generate the tidy dataset.
* `README.md`: This file, which explains how the scripts work and how the files are connected.

## How to Run the Script

1. Open your R console or RStudio.
2. Ensure you have the `dplyr` package installed (`install.packages("dplyr")`).
3. Save the `run_analysis.R` script into your working directory.
4. Run the script using the command: `source("run_analysis.R")`.
5. The script will automatically download the dataset (if it isn't already downloaded), unzip it, perform the data cleaning processes, and generate a file named `tidy_data.txt` in your working directory.

## How `run_analysis.R` Works

The script operates in the following sequential steps, satisfying the project requirements:

1. **Setup and Download:** 
   Checks if the `dplyr` package is installed. It then checks if the data archive exists in the working directory; if not, it downloads and unzips it.
   
2. **Step 1: Merges the training and the test sets to create one data set.**
   Reads into tables the features, activities, and the training and test datasets (`X`, `y`, and `subject` files). It merges the training and test sets using `rbind()`, and then binds the subject, activity, and feature columns together using `cbind()`.

3. **Step 2: Extracts only the measurements on the mean and standard deviation for each measurement.**
   Uses the `dplyr::select()` function to subset the dataset, keeping only the `subject`, `code` (activity), and any columns containing the strings "mean" or "std".

4. **Step 3: Uses descriptive activity names to name the activities in the data set.**
   Replaces the numeric activity codes (1 through 6) in the dataset with their corresponding descriptive string labels (e.g., WALKING, STANDING) taken from the `activity_labels.txt` file.

5. **Step 4: Appropriately labels the data set with descriptive variable names.**
   Uses regular expressions (`gsub()`) to clean up the column names. It removes special characters and expands abbreviations to make the variable names human-readable (e.g., replacing `Acc` with `Accelerometer`, `Gyro` with `Gyroscope`, `^t` with `Time`, etc.).

6. **Step 5: Creates a second, independent tidy data set with the average of each variable for each activity and each subject.**
   Groups the cleaned data by `subject` and `activity` using `dplyr::group_by()`, and calculates the average for each measurement using `summarise_all(mean)`. Finally, it exports this tidy dataset to `tidy_data.txt` using `write.table()` with `row.names = FALSE`.
